# Use HARVEY for pricing intelligence

HARVEY is SPHERE's conversational pricing-intelligence assistant. Open **Tools → HARVEY** to work in standalone mode, or use the **H** button in a pricing card for a conversation already grounded in that pricing version.

## Ask a question about a pricing

1. Open HARVEY.
2. Select a suggested prompt or type a question in **Ask about pricing strategies**.
3. Select **Ask**.
4. Review the streamed answer and its quantitative findings.

![HARVEY standalone workspace](/img/sphere/user-guide/harvey.png)

Example questions include:

- “Which is the cheapest plan that includes API access?”
- “Compare the collaborator limits across these pricings.”
- “Identify redundant plans and explain the effect of removing one.”

## Add pricing context

You can provide context in three ways:

1. **Stored pricing**: select **Search**, search the SPHERE catalogue, and attach a pricing.
2. **External URL**: enter a public pricing-page URL in the `https://...` field and select **Add**. HARVEY extracts it before analysis.
3. **Current pricing card**: open HARVEY from a pricing card; the active version is supplied automatically.

![HARVEY stored-pricing context](/img/sphere/user-guide/harvey-context.png)

:::caution
External pages can take longer to analyse because HARVEY must first extract pricing information. Verify important findings against the source before using them in a commercial decision.
:::
