# Discover public pricings and collections

## Search public pricings

1. Select **Explore → Pricings**.
2. Enter a product name in **Search by name**.
3. Select **Filters** to narrow the results using the available pricing metrics.
4. Open a card to inspect the pricing, its organization, collection, version, configuration count, and price range.

![Public pricing catalogue](/img/sphere/user-guide/pricing-search.png)

The catalogue only exposes public pricings. Private resources can be opened only by authorized organization members or users granted entity-level access.

## Search public collections

1. Select **Explore → Collections**.
2. Search by collection name.
3. Optionally filter by owner.
4. Open a collection to browse its metadata and the pricings it contains.

:::info
A collection is a curated group of related pricings. It can contain one pricing with multiple versions, or several distinct pricings, depending on the dataset or collaboration workflow.
:::
