# Manage your account, API keys, and notifications

Open the avatar menu to access **Inbox**, **Organizations**, **API Keys**, and **Settings**.

![Account menu](/img/sphere/user-guide/account-menu.png)

## Create an API key

1. Select **API Keys**.
2. Select **Create new API key**.
3. Give the key a recognizable name.
4. Select the organization and appropriate scope.
5. Create the key and store the displayed secret in an approved secret manager.

![API key creation](/img/sphere/user-guide/api-key-form.png)

API-key scope caps the rights granted through the key:

- **View** is limited to the permissions of an ordinary member.
- **Management** is limited to the permissions of an organization admin.
- **All** does not further reduce the caller's own authorized rights.

Revoke a key when it is no longer needed. Delete stale key records after confirming that no application uses them.

## Update account settings

1. Select **Settings** from the avatar menu.
2. Use the relevant tab to update account details, public profile, social links, notification preferences, or payments.
3. Save the change.

![Account settings](/img/sphere/user-guide/account-settings.png)

Use **Inbox** to review organization invitations and platform notifications.
