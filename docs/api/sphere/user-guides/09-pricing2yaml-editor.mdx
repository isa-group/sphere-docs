# Use the Pricing2Yaml Editor

Open **Tools → Pricing2Yaml Editor** or go to [the editor](https://sphere.score.us.es/editor). The editor supports code and visual modes, live validation, live rendering, imports, exports, and shareable links.

![Pricing2Yaml Editor](/img/sphere/user-guide/editor.png)

## Edit in code mode

1. Keep **Code** selected.
2. Enter or edit Pricing2Yaml source.
3. Review validation feedback and the rendered pricing preview as you type.
4. Fix syntax errors before exporting or uploading the document.

## Use visual mode

Select **Visual (beta)** to model the pricing interactively without editing YAML directly. Switch back to code mode at any time to inspect the generated source.

![Visual pricing editor](/img/sphere/user-guide/visual-editor.png)

## Manage the editor file

Select **File** and then choose one of the available actions:

- **Reset** restores the editor's starting state.
- **Import YAML** loads a local Pricing2Yaml file.
- **Clear** removes the current source.

![Editor file actions](/img/sphere/user-guide/editor-file-menu.png)

## Export or share

Select **Export**, then choose **Download YAML** to save the document or **Share Link** to create a URL that reproduces the current editor state.

![Editor export actions](/img/sphere/user-guide/editor-export-menu.png)

:::info
The editor supports the current Pricing2Yaml syntax. Consult the [Pricing2Yaml documentation](../../pricing-description-languages/Pricing2Yaml/the-pricing2yaml-syntax.md) for the language reference.
:::
